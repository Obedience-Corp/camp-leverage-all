# Camp Leverage All 0.3.0

Run `camp leverage-all` to see COCOMO effort and estimated dollars across every
registered Camp, with each repository counted once.

- Default dollars in the headline, period and cumulative timeline, and each repository.
- Responsive repository details keep dollar estimates visible in narrow terminals.
- Explicit cost assumptions: $56,286 annual wage, 2.4× overhead, organic COCOMO.
  Use `--annual-wage` and `--overhead` to adjust them.
- Native Linux and macOS archives for x86_64 and arm64 bundle Python and `scc`.
  Camp and Git are required on `PATH`. Linux requires glibc 2.36+; macOS builds
  target macOS 15+.
- JSON includes full-precision personal and whole-repository costs, model assumptions,
  and period/cumulative estimates. The timeline allocates today's code estimate
  across authored history; its final cumulative total matches the headline.

The official Festival marketplace listing is pending. Users with repository access
can install this tagged version using Python 3.11+, `scc` 3.7+, and `uv`:

```sh
uv tool install --force git+ssh://git@github.com/Obedience-Corp/camp-leverage-all.git@v0.3.0
camp leverage-all --version
camp leverage-all
```

Release archives include license notices under `assets/licenses` and build metadata
under `assets/build-info.json`. Verify archive downloads against `checksums.txt`.
