# Security policy

## Supported versions

Camp Leverage All is pre-1.0. Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository:

<https://github.com/Obedience-Corp/camp-leverage-all/security/advisories/new>

Include the affected version, reproduction steps, impact, and any suggested mitigation.

Camp Leverage All runs local `camp`, `git`, `ssh`, and `scc` commands and reads repository history. Reports may contain local paths and Git author email addresses. Review JSON output before sharing it.
